# Budget Tracker landing page

A one-page site that explains the app and points people to it. It is plain HTML with no scripts, no trackers and no outside fonts, so it loads fast and matches the app's "nothing leaves your device" promise.

## Put it online (about two minutes)

1. Open your GitHub repo (the one that holds the app).
2. Choose **Add file → Upload files**, then drag in the whole **about** folder from this zip.
3. Commit. GitHub Pages publishes it within a minute or two.
4. Your page is at: https://geiger12.github.io/BudgetTracker17/about/

Share that link, not the app link, when you want to explain the app. The **Open the app** buttons take people to the app itself.

## What is in the folder

- `about/index.html` the page
- `about/preview.png` the 1200 × 630 card that shows when the link is pasted into a message or post
- `about/img/` the app screens used on the page

## If your repo or username changes

Four lines near the top of `index.html` hold the full web address (canonical, og:url, og:image, twitter:image). Change `https://geiger12.github.io/BudgetTracker17/about/` in those lines to the new address.

## Check the link preview

Platforms keep the first preview they see, so test before you post:

- Facebook and Instagram: Sharing Debugger (developers.facebook.com/tools/debug)
- LinkedIn: Post Inspector (linkedin.com/post-inspector)
- Messages and X: paste the link in a draft and look

## Notes

- There is no analytics on the page. To see visits, open your repo, then **Insights → Traffic**.
- Every claim on the page describes the app as it is today: no account, saved on the device, filters, schedule view, colors, share by link, backup file. If you add features, update the page to match.
- The iPhone steps use Apple's usual wording (Share, then Add to Home Screen).
